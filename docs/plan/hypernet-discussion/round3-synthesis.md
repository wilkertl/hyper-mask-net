# Round 3 · Which selector parameters can an unseen corpus predict?

Astra's synthesis for Opus-E and Opus-M to sign or dissent. Thresholds, sample sizes and architecture choices below are prospective.

## 1. Decision summary

Run the supervised oracle ladder on SciFact, NFCorpus and MS MARCO first. It measures what changing the prior, bias or query response could buy with the same frozen global selector.
The deployment comparator is a corpus-balanced global selector with the recipient's document variance and shared budget weights (G+V).
First predict an offset and slope across budgets. Test a single offset inside this model. Build a tied coordinate bias and then a rank-four residual only after incremental held-family retrieval gains.
Freeze the base before learning the map from corpus statistics. Reserve all payoff measurements that influence development for meta-train.
Use P0 for the proposed primary claim. P1 answers a separate question about access to unlabeled calibration queries.
Evaluate one locked candidate on exact, equal-family, nine-budget mean nDCG@10. A powered superiority result and evidence of safe deployment are distinct outcomes.
Treat the current program as exploratory until the split audit and prospective family-level power analysis qualify a confirmatory test.

## 3. Architecture

Let q,d be normalized frozen Qwen3-Embedding-0.6B vectors of width D=1024. Use column vectors, j for coordinate, and i=1,…,9 for kᵢ=floor(iD/10). From the unchanged document matrix compute population variance vₜ[D]. Define pₜ(q)=log(q² ⊙ vₜ + 10⁻¹²) elementwise. All rungs use the same S4 logits

**sₜᵢ(q) = Wq + b + aₜᵢ pₜ(q) + cₜ + Aₜ(Bq).**

Absent terms are zero. Select the kᵢ largest logits, resolving equal scores by coordinate ID. Evaluate the exact dot product (q ⊙ mask)ᵀd over the whole unchanged collection without normalizing the masked query. Resolve document-score ties by a fixed document ID order and apply the same identical-ID exclusions in every arm. At D, bypass selection and require identical full-dimensional rankings. Use identical scoring precision and verify against a float64 reference including near ties.

| Rung | Parameters and output | Shared learned parameters added | Generated values cached per corpus, cumulative |
|---|---|---:|---:|
| G+V | W[D,D], b[D], a⁰[9]≥0. Set aₜ=a⁰. | 1,049,609 | 0 |
| HyperPrior | Standardized φₜ[3]. Generate u,v = Cᵀφₜ, C[3,2]. With tᵢ=(i−5)/4, set aₜᵢ=max(0,a⁰ᵢ+u+tᵢv). Offset-only ablation fixes v=0. | 6 (3 for ablation) | 9 weights, equivalently 2 scalars plus shared decoding |
| Tied bias | Standardized departure rows Xₜ[D,h]. cₜ=Xₜw, w[h]. Add to b offline. | h = 18 P0 or 43 P1 | 1,033 |
| Rank four | Aₜ=XₜH, H[h,4], shared B[4,D]. Cache Aₜ[D,4] and apply the factors in sequence. | 4h+4,096 = 4,168 P0 or 4,268 P1 | 5,129 |

The variance buffer, descriptor reference moments and deterministic budget grid are data, outside the learned counts. Stage A initializes W,b to zero and a⁰ to ones as in S4, then fits and freezes G+V. Initialize C,w,H to zero and B with four seeded orthonormal rows. Thus the full initial model equals the fitted G+V at every budget, and appending a zero residual later preserves the accepted lower rung. A nonzero B lets H receive its first gradient. The projection admits exact zero. Fit prior targets in weight space with W,b fixed and the identical projection at inference. Report utility curves and S4's mean per-query ratio SD(a p)/(SD(a p)+SD(linear correction)), flagging a zero denominator. Standardizing each score component separately would change the comparator.

**Descriptor contract.** Compute φ for P0 from log document count, log participation ratio log(tr(Σ)²/tr(Σ²)), and anisotropy λmax(Σ)/tr(Σ), with Σ the document covariance. For P1 replace anisotropy with mean top-one full-vector cosine on the calibration queries. Require positive covariance trace, flag degenerate descriptors and fall back to G+V. P0 rows use the existing document marginal, tail and redundancy features. P1 adds query marginals, query-document products and top-20 versus seeded background contrast. Hash-sample 500 distinct unlabeled non-evaluation queries per eligible corpus before fitting, with a disjoint query-ID and near-duplicate audit. Without this pool only P0 is eligible. Freeze instructions, model revision, row ordering, sample seeds and feature names. Follow the existing streaming and hashed quantile rules. No qrels loader is reachable from either descriptor path.

Center each row at the family-balanced training mean for that coordinate and feature, divide by the corresponding training SD (floor 10⁻⁶). Apply the same rule across training corpora for φ. In cross-fitted training exclude the pseudo-target family from these moments. Store the final reference moments alongside the checkpoint. All adapted outputs are computed once from the recipient's permitted inputs.

**Costs.** Time and report embedding, streamed moments O(ND), covariance O(ND²) time/O(D²) working storage, spectral summaries, and P1 calibration encoding and exact search O(500ND) separately. Record residual generation O(Dh) for bias and O(4Dh) for loadings, checkpoint bytes, device, peak memory and wall time. Online, HyperPrior and the folded bias have G+V's work. Rank four adds 8,192 multiply-accumulates per query. Measure encoding, projection, mask and exact scoring separately. A sparse query saves wall time only if the retrieval kernel realizes the saving.

## 4. Training

1. **Stage A, pooled selector.** In each outer leave-one-corpus-out (LOCO) episode, hold out the corpus **and its entire source family**. Draw a source corpus uniformly, then training queries uniformly inside it and a decile uniformly. Use same-corpus batches so cross-corpus documents cannot become accidental negatives. Train the pooled S4 score with that source's variance, differentiable soft top-k, the existing temperature schedule and multi-positive masked retrieval loss. For positive weights y summing to one and logits ℓ(d)=(q⊙softmask)ᵀd/τ, minimize −Σ₊ y(d)[ℓ(d)−logΣ_candidates exp ℓ]. Use only training positives and same-split hard negatives, retaining the existing in-batch exclusion rules. Select checkpoints by hard-mask exact validation retrieval on source families under the S4 guard. Compare a family-uniform then corpus-uniform sampler as a sensitivity analysis.
2. **Stage B, cross-fitted generator.** Inside each outer training pool, rotate an inner pseudo-target family. Fit Stage A without it, freeze the base, compute its descriptor from permitted inputs, fit supervised oracle residuals on its training query partition, select on a disjoint non-test partition and reserve independent queries for regret measurement. These inner families supply training examples for the descriptor map. Fit C by equal-corpus least squares to the attainable oracle's projected nine weights plus an L2 penalty. Use the same projected forward equation during fit and inference, with a boundary-capable optimizer (include zero and feasible positive directions explicitly). Compare the single-offset restriction on the same folds. For w and H,B use episodic masked retrieval loss plus squared generated-logit RMS penalty, freezing accepted lower terms. Select penalties and stopping inside source folds. Average three preassigned training seeds. Refit the base on all outer sources for deployment to the outer family. Apply the learned map without gradients or held-family judgments. Repeat the entire procedure for the final meta-train pool.
3. **Why stage it.** Jointly changing W and the weight head can rescale both terms while preserving the masks. It can also allocate more updates to the base and misattribute a stronger global selector to conditioning. The staged experiment asks whether a recipient descriptor predicts a useful residual on a reproducible base. Use identical initialization, source draws, labels, budgets, validation opportunities and updates for the corresponding controls. Check for variation in base scale across folds and report the error from transferring the cross-fitted calibration onto the final refit.

Register the following rules and exclusions before opening fresh outcomes. Δ always means a paired difference in the family endpoint in §6. A screening failure retains the last qualified rung. Report uncertainty when a failure reflects limited precision.

## 6. Evaluation

**Pool and split.** SciFact, NFCorpus and MS MARCO are permanently development/meta-train. Candidate additions with independently documented non-test labels include FiQA, the NQ/HotpotQA/FEVER Wikipedia cluster, and, subject to audit, Quora, LoTTE development and licensed BioASQ. Candidate evaluation sources include ArguAna/Touché, SCIDOCS, TREC-COVID, Robust04/TREC-NEWS, Signal-1M and CQADupStack. These are nominations, not counts. Before scoring, group shared source documents, related queries, derivatives and near duplicates by connected components (flag ≥1% overlap of the smaller collection for review). Treat Wikipedia derivatives and overlapping StackExchange sources as single families. Audit scientific and biomedical collections for common sources. Hash and publish membership, rationale and exclusions. Synthetic mixtures, topic shards, instructions, seeds and budget settings contribute zero additional families.

Reserve two fresh families with genuine non-test validation labels for meta-validation; allocate remaining eligible training-label families to meta-train and untouched evaluation-only families to meta-test, targeting 8–12 **after** reserving validation. Use a fixed seed within eligibility and source strata where choices remain. If official test qrels are the only labels, they are usable solely for the single locked evaluation. They cannot finance training, checkpoint choice, the census, mining, or meta-validation. Never fit a reference on any label of a meta-test corpus, including an official training split. Commit the assignment and feasibility downgrade before any new-corpus payoff measurement. Keep P2 on a separately allocated family pool with lawful labeled support disjoint from evaluation. P2 has no role in selecting or scoring the zero-shot claim.

**Estimand.** For the same query and seed, difference exact linear-gain nDCG@10, average equally across nine deciles, then average seeds and queries, corpora within family, and families. Freeze query eligibility including exclusions before scoring. The pairing and equal family weights carry through every comparison. Use float64 exact full-corpus scoring, fixed row-ID tie ordering and the registered inclusion rules. Check parity at 1024 and check hard masks have exactly k entries. P0 is primary because every recipient can supply documents. Compare P1 against P0 on identical eligible corpora, using the disjoint calibration panel only. Report k=307 for E1 continuity, all budget curves, MRR@10/100, Recall@100, prior shares and mask overlap as secondary outcomes.

**Statistics and power.** Primary hypothesis is superiority of the locked P0 arm over G+V at zero, one-sided α=0.05. Predeclare a fixed sequence for further claims: superiority over the matched global, then superiority over the donor. Stop formal testing at the first failure. Only passage of all three supports the descriptor-specific attribution. Keep one primary candidate. Holm-adjust secondary arm contrasts within a prespecified family and budget-specific contrasts jointly across budgets. Report paired query intervals and tests inside corpora as diagnostics. They supply no extra degrees of freedom to the cross-family test.

For each primary contrast enumerate all family sign flips of the paired differences and compare the observed equal-weight mean with the resulting null distribution. Invert shifted tests for location intervals under independent sign-symmetric family errors. Symmetry is a substantive assumption for heterogeneous families. Show the individual effects, signs, delete-one estimates, paired hierarchical bootstrap and a random-effects REML prediction interval for a new family with small-sample uncertainty. Mark prediction intervals unstable at small K. LOFO training screens share source fits and their p-values are screening diagnostics. A permutation must repeat the entire fit and selection under the null.

A practical point gain is +0.005. Detecting it with 80% power at family SD 0.010 already requires roughly 25 independent families by the *one-sided normal approximation*, before finite-sample penalties. At 8–12 families design for a true +0.010 against zero. Neither a minimum effect of +0.010 nor non-inferiority at −0.005 follows from that test. Before opening fresh labels, register simulations of the exact test and stopping rules at SD 0.008, 0.010 and 0.015, including asymmetric and null scenarios. Before release of test qrels rerun with locked K, development heterogeneity (including its upper 80% confidence limit), paired query uncertainty and correlations between arms. Use ≥10,000 draws. Require null rejection ≤0.055 and ≥80% power for the primary test at +0.010 under the conservative development SD. Evaluate joint attribution power separately with prespecified +0.010 against each of its controls. Do not infer joint power from one comparison.

**Claim level.** Below eight test families, or when simulation fails the primary criterion, the study reports estimates and replication counts only. At 8–14, a qualified result can confirm the registered mean contrast for the audited evaluation panel. Broader population generalization remains exploratory. At ≥15 independent families consider transport to the stated sampling frame only if the same power check passes, sampling supports it and delete-one means remain positive. Require the joint simulation and all ordered tests for confirmatory attribution. All oracle recovery, G3 extensions, donor equivalence, protocol interactions and P2 findings remain exploratory here. No ±0.002 equivalence requirement.

**Family harm guard.** Define material harm as Δ_f<−0.010 versus G+V. Within each family, resample paired queries within each member corpus and preserve equal corpus weights, budgets and seeds. Test the lower-tail harm hypothesis against the boundary and apply Holm across families. Show simultaneous two-sided Bonferroni intervals against −0.010. Significant harm blocks a deployment recommendation. A family whose interval crosses the margin has unresolved risk. Excluding material harm across this panel requires every simultaneous lower bound above the margin. Neither a positive average nor zero harm discoveries establishes safety for a new family.

## 8. Kill criteria and expected outcomes

My prior is that rebuilding G+V removes some apparent NFCorpus headroom, that SciFact retains some, and that the fitted prior helps a subset of families. I place less confidence in predicting a bias from document statistics and least in a reproducible rank-four increment. These are directional judgments. No reported project comparison estimates the incremental rank-four effect. Opus-E's sharper SciFact prediction is registered in §5. Opus-M expects heterogeneous gains and stronger P1 results. A positive P1 result paired with a flat P0 result would narrow the claim to environments with calibration queries.

Three negative results would lead to different decisions. If specialist headroom is small even at its upper bound, finish with G+V. If supervised residuals help but cross-fitted descriptors or donor tests fail, publish the attainable oracle gain and the prediction failure separately. If a lower rung passes and a richer one fails, retain the lower one. A rank oracle failure speaks only to the tested basis and optimization budget. For a locked estimate with a one-sided upper 95% bound below +0.005, retire the practical-gain claim on this panel. A wide interval crossing zero and +0.005 leaves it unresolved. Meta-test outcomes cannot trigger a second selection on the same families.

For G5 report break-even queries against each rival as excess offline time divided by positive per-query time saved, with both times on the same hardware and batch policy. Negative or zero saving with positive offline cost gives no break-even. Losing to a cheaper rival ends the deployment case under the stated workload even if a detector finds a mean gain over G+V.

## 9. Risks and threats to validity

- **Selection into the pool.** Label-bearing sources may be systematically different from evaluation-only sources. Record language, collection construction, query style, judgment density, instruction and known/unknown encoder training exposure. Equal-family weighting addresses repeated sources; transport beyond eligible families still requires an argument about sampling.
- **Query shift and size confounding.** Freeze instructions before opening outcomes. Show gains against log-size-only and nearest-source controls, distance to the nearest source, and P0/P1 pairs at matched sample size. Test-only sources with no independent calibration pool cannot contribute to the P1 comparison. Report its reduced K.
- **Thin supervision and weak ceilings.** Specialists differ in examples per query and judgment completeness. Report common-label-count sensitivity, seed and split-half retrieval regret, and absolute scores. A small or negative H makes fractional recovery unstable. Rank factors can rotate without changing a score, so use observable logits and utility for stability.
- **Scale, ties and optimizer artifacts.** Prior weights can stay at initialization, many coefficients can yield the same hard mask, and a linear budget trend can miss abrupt cutoff behavior. Report endpoints, zero frequency, score spreads, oracle F2 versus F9, kept-step and alternate-seed gains. Verify the rank branch receives gradients and the matched global changes its predictions. Register the optimizer/search budget before comparing ceilings.
- **Alternative explanations.** An offline descriptor can encode family identity, and a pseudo-query method can buy stronger adaptation at greater cost. Include lookup and both retrieval-time feedback rivals. PRF-DIME weights coordinates by query times top-document centroid (DIME, §3, eq. 5, p. 5). Eclipse also uses bottom-of-list pseudo-negative evidence (Eclipse, §3, eq. 1, p. 3). Charge both retrieval passes. Learning to Select's pseudo-query experiment motivates the separate offline rival (§6.5, Table 5, p. 8). None of these experiments tests the proposed corpus-to-parameter map.
- **Precision and multiplicity.** Overlapping LOCO training folds and optimistic development gaps can inflate projected power. Predeclare asymmetric simulations, paired uncertainty, limited candidate count, joint power and leave-one-family sensitivity. Keep the observed panel and new-family prediction interval visible even after a primary pass.
- **Compute and leakage.** Freeze a small/medium/large resource plan before opening labels. Record missing or incomplete families as attrition, with the predeclared downgrade. The evaluator alone can open final qrels after the lock. Keep a provenance chain for descriptor inputs, miners, checkpoints, and the exact scoring process.
